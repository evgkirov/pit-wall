# PitWall v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A local macOS chat reader — read-only Twitch chat spoken aloud via `say`, on a typed-channel plugin architecture.

**Architecture:** asyncio runtime with three typed channels (`messages`, `speak`, `audio`); plugin-keyed array config (`[[plugin.name]]`) instantiating plugins by alias; per-segment target routing; TTS plugins synthesize parts to audio files tagged `(request_id, index)` and the output plugin sequences and plays them.

**Tech Stack:** Python 3.15+ (pin bends to the newest twitchio supports), uv, twitchio, watchfiles, pytest + pytest-asyncio, ruff.

**Spec:** `docs/superpowers/specs/2026-11-22-pitwall-design.md`

## Global Constraints

- Naming: `pitwall` for files/dirs/packages; `PitWall` in README/prose.
- Entrypoint: Makefile — `make run` (wraps `uv run pitwall`); also `make test`, `make lint`.
- Config: `$XDG_CONFIG_HOME/pitwall/config.toml`, fallback `~/.config/pitwall/config.toml`; plugin-keyed arrays `[[plugin.name]]`; optional `alias` per instance, defaulting to the plugin name's last dotted component; duplicate aliases (explicit or derived) are config errors.
- TTS plugins only **synthesize** audio to files tagged `(request_id, index)`; only output plugins play audio — sequencing is the output's job.
- Twitch connection is read-only: anonymous (`justinfan`) preferred, app token (`chat:read`) fallback; the bot never sends chat; no user OAuth.
- No `!ping` / command handling in v1.
- `uv` manages dependencies; `make lint` (ruff check + format check) passes at every commit; tests run under pytest with `asyncio_mode = "auto"`.
- Layout: `src/pitwall/` package; console script `pitwall = pitwall.cli:main`.
- Plugin contract: every plugin exposes `name: str`, `async start(ctx)`, `async stop(ctx)`. `start()` runs until the plugin is done (normally when `ctx.stopping` is set); `stop()` cleans up.

## Review Focus

- Malformed or missing config at cold start → one-line error naming the path, exit 1, no traceback. (Task 11)
- `say` or `afplay` binary missing → error logged, bot keeps running. (Task 8)
- Unknown filter name in config → build-time error before any message flows. (Task 7)
- A lost audio part (synthesis failed for one segment) → the output's stall timeout flushes the partial request; the queue never blocks forever. (Task 8)
- Config change while events are mid-queue → rebuild without hang or loss of the old graph's shutdown. (Task 10)

### Task 2: Channels with per-target splitting

**Files:**
- Create: `src/pitwall/core/channels.py`, `tests/test_channels.py`

**Interfaces:**
- Consumes: `pitwall.core.events` (Task 1).
- Produces:

```python
def split_by_target(request: SpeakRequest) -> list[tuple[str | None, SpeakRequest]]
# group segments by effective target (segment.target or request.target);
# one (target, sub_request) per distinct target, segments keep their original
# indices; all-targetless → [(None, request)]

class Channel(Generic[T]):
    def __init__(self, name: str,
                 splitter: Callable[[T], list[tuple[str | None, T]]] | None = None) -> None: ...
    def subscribe(self, instance: str) -> asyncio.Queue[T]: ...
    def unsubscribe(self, instance: str) -> None: ...
    async def publish(self, event: T) -> None: ...
# delivery: with a splitter, each (target, sub) goes to that instance (or all when
# None); without, the whole event goes to getattr(event, "target", None) or all.
```

Queues are unbounded in v1 (backpressure policy left open by the spec). The runtime wires `Channel("speak", splitter=split_by_target)`; `messages`/`audio` get no splitter.

### Task 4: Config loading + validation

**Files:**
- Create: `src/pitwall/core/config.py`, `tests/test_config.py`

**Interfaces:**
- Produces (used by the runtime, CLI, watcher):

```python
class ConfigError(Exception): ...   # message is user-facing; names the offending table/key
@dataclass(frozen=True)
class InstanceSpec:
    name: str          # the RESOLVED alias
    plugin: str
    config: dict       # table minus alias/enabled
    enabled: bool = True
@dataclass(frozen=True)
class Config:
    instances: tuple[InstanceSpec, ...]
def load_config(path: Path) -> Config
```

Parsing: every top-level key is a plugin name; its value must be an array of tables. Per table: `alias` optional string — default `plugin.split(".")[-1]`; `enabled` bool default `true`; the rest is config. Validation: value not an array of tables → `ConfigError`; duplicate aliases (explicit or derived) → `ConfigError` naming both; a `target` in any instance config must name an *enabled* alias; parse errors and missing file → `ConfigError`.

Factory = Callable[[], Plugin]

### Task 7: handler.tts — filters, template segments, voices, routing

**Files:**
- Create: `src/pitwall/plugins/__init__.py`, `src/pitwall/plugins/handler_tts.py`, `tests/test_handler_tts.py`

**Interfaces:**
- Consumes: `Context` (Task 3), events (Task 1), `Channel` (Task 2).
- Produces (registered in `pitwall.plugins` as `"handler.tts"`):

```python
Filter = Callable[[Message], bool]            # True = speak it
FILTERS: dict[str, Callable[[dict], Filter]]  # name -> factory(filter_config)
# built-in: "min_length" — pass iff len(text) >= cfg.get("min", 2)
def render(template: str, message: Message, voices: dict[str, str],
           targets: dict[str, str] = {}, target: str | None = None) -> tuple[Segment, ...]
class TtsHandlerPlugin:  name = "handler.tts"
```

Config keys: `template` (default `"{user} says: {text}"`; allowed placeholders `{user}`, `{text}`), `filters` (inline ordered table `name → config`, default `{}`), `voices` (placeholder → voice key), `targets` (placeholder → alias), `target` (request-level alias). Behavior: subscribe to `ctx.messages` as `ctx.instance`; skip `kind != "chat"`; run the filter chain in order (all must pass); per message build `SpeakRequest(request_id=uuid4().hex, segments=render(...), source=m.source, user=m.user, target=cfg target)` and publish to `ctx.speak`. Unknown filter name or unknown template placeholder → `ValueError` **at construction** (fails at graph build, before any message flows).

`render` rule: split the template on `{user}`/`{text}`; a placeholder becomes `Segment(value, voice=voices.get(key), target=targets.get(key) or target, index=n)`; a literal run becomes `Segment(literal, voice=..., target=...)` **inheriting the preceding placeholder's voice key and target**; indices assigned in order. So `"{user} says: {text}"` with `voices={"user": "samantha", "text": "daniel"}` and `targets={"text": "cloud"}` yields texts `["alice", " says: ", "hi"]`, voices `["samantha", "samantha", "daniel"]`, targets `[None, None, "cloud"]`.

### Task 8: tts.say (synthesizer) + output.local (sequencer/player)

**Files:**
- Create: `src/pitwall/plugins/tts_say.py`, `src/pitwall/plugins/output_local.py`, `tests/test_tts_say.py`, `tests/test_output_local.py`

**Interfaces:**
- Consumes: `Context`, `SpeakRequest`/`Segment`/`Audio`, `Channel`.
- Produces (registered later as `"tts.say"` / `"output.local"`):

```python
# tts_say.py
def resolve_voice(config: dict, key: str | None) -> str | None
# None key -> config.get("voice"); known key -> config["voices"][key];
# unknown key -> config.get("voice") (the PLUGIN logs the warning naming the key)
def synth_args(config: dict, segment: Segment, out_path: str) -> list[str]
# ["say", "-o", out_path] + (["-v", voice] if resolved) + (["-r", str(rate)] if set) + [text]
async def create_subprocess(args: list[str]) -> None   # exec + await; tests monkeypatch this seam
class SayTtsPlugin:  name = "tts.say"

# output_local.py
async def create_subprocess(args: list[str]) -> None   # seam for afplay
class LocalOutputPlugin:  name = "output.local"  # config: stall_timeout: float = 5.0
```

`SayTtsPlugin.start`: subscribe to `ctx.speak` as `ctx.instance`; per sub-request, per segment **in order**: resolve the voice (unknown key → warning, default), create a temp file (`tempfile.mkstemp(suffix=".aiff")`), `await create_subprocess(synth_args(config, segment, path))`, publish `Audio(path=path, request_id=req.request_id, index=segment.index, source=req.source, user=req.user)` to `ctx.audio`. It never plays audio.

`LocalOutputPlugin.start`: subscribe to `ctx.audio`; keep `buffer: dict[request_id, dict[index, path]]` and `next: dict[request_id, int]`; on each event, buffer it and drain: while `next[rid]` is buffered, `await create_subprocess(["afplay", path])`, then `Path(path).unlink(missing_ok=True)`. If no event arrives for `stall_timeout` seconds (queue get with timeout), flush any buffered parts in index order with a WARNING naming the request, and drop the rest of that request.
