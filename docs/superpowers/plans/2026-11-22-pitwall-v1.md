# PitWall v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A local macOS chat reader — read-only Twitch chat spoken aloud via `say`, on a typed-channel plugin architecture.

**Architecture:** asyncio runtime with three typed channels (`messages`, `speak`, `audio`); config-driven plugin instances (one TOML table per instance) with target-based delivery and per-part voice keys; config watched, plugin graph rebuilt in-process.

**Tech Stack:** Python 3.15+ (pin bends to the newest twitchio supports), uv, twitchio, watchfiles, pytest + pytest-asyncio, ruff.

**Spec:** `docs/superpowers/specs/2026-11-22-pitwall-design.md`

## Global Constraints

- Naming: `pitwall` for files/dirs/packages; `PitWall` in README/prose.
- Entrypoint: Makefile — `make run` (wraps `uv run pitwall`); also `make test`, `make lint`.
- Config path: `$XDG_CONFIG_HOME/pitwall/config.toml`, fallback `~/.config/pitwall/config.toml`.
- Twitch connection is read-only: anonymous (`justinfan`) preferred, app token (`chat:read`) fallback; the bot never sends chat; no user OAuth.
- No `!ping` / command handling in v1.
- `uv` manages dependencies; `make lint` (ruff check + format check) passes at every commit; tests run under pytest with `asyncio_mode = "auto"`.
- Layout: `src/pitwall/` package; console script `pitwall = pitwall.cli:main`.
- Plugin contract: every plugin exposes `name: str`, `async start(ctx)`, `async stop(ctx)`. `start()` runs until the plugin is done (normally when `ctx.stopping` is set); `stop()` cleans up.

## Review Focus

- Malformed or missing config at cold start → one-line error naming the path, exit 1, no traceback. (Task 11)
- `say` binary missing (non-macOS, PATH) → error logged, bot keeps running. (Task 8)
- Unknown filter name in config → build-time error before any message flows. (Task 7)
- Unicode/emoji chat text → reaches the `say` argv unchanged. (Task 8)
- Config change while a request is mid-queue → rebuild without hang or loss of the old graph's shutdown. (Task 10)

### Task 2: Channels with targeted delivery

**Files:**
- Create: `src/pitwall/core/channels.py`, `tests/test_channels.py`

**Interfaces:**
- Consumes: `pitwall.core.events` events (Task 1).
- Produces: `Channel[T]` — `__init__(self, name: str)`, `subscribe(self, instance: str) -> asyncio.Queue[T]`, `unsubscribe(self, instance: str) -> None`, `async publish(self, event: T) -> None`. Rule: deliver to the instance named by `getattr(event, "target", None)`, or to every subscriber when it is `None`. Queues are unbounded in v1 (backpressure policy is left open by the spec).

### Task 4: Config loading + validation

**Files:**
- Create: `src/pitwall/core/config.py`, `tests/test_config.py`

**Interfaces:**
- Produces (used by the runtime, CLI, watcher):

```python
class ConfigError(Exception): ...   # message is user-facing; always names the offending table/key
@dataclass(frozen=True)
class InstanceSpec:
    name: str          # the TOML table name = instance ID
    plugin: str
```

### Task 5: Registry + runtime (build, start, stop)

**Files:**
- Create: `src/pitwall/core/registry.py`, `src/pitwall/core/runtime.py`, `tests/test_registry.py`, `tests/test_runtime.py`

**Interfaces:**
- Consumes: `InstanceSpec`/`Config` (Task 4), `Plugin`/`Context` (Task 3), `Channel` (Task 2).
- Produces:

```python
Factory = Callable[[], Plugin]
class UnknownPluginError(Exception): ...   # carries the plugin name
def register(name: str, factory: Factory) -> None
def build(spec: InstanceSpec) -> Plugin    # raises UnknownPluginError

class Runtime:
    def __init__(self, backoff_start: float = 1.0, backoff_cap: float = 30.0) -> None: ...
    async def start(self, config: Config) -> None: ...
    async def stop(self) -> None: ...
```

`start`: create fresh `Channel("messages"|"speak"|"audio")`; **build every enabled plugin first** (an `UnknownPluginError` must abort before anything starts); per instance create `Context(instance=spec.name, config=spec.config, logger=logging.getLogger(f"pitwall.{spec.name}"), ...)` and launch its supervised task (supervision added in Task 6). `stop`: set every `ctx.stopping`, await all tasks (timeout 5s), then call each `plugin.stop(ctx)`.

### Task 7: handler.tts — filters, template segments, voices, target

**Files:**
- Create: `src/pitwall/plugins/__init__.py`, `src/pitwall/plugins/handler_tts.py`, `tests/test_handler_tts.py`

**Interfaces:**
- Consumes: `Context` (Task 3), `Message`/`Segment`/`SpeakRequest` (Task 1), `Channel` delivery rule (Task 2).
- Produces (registered in `pitwall.plugins` as `"handler.tts"`):

```python
Filter = Callable[[Message], bool]          # True = speak it
FILTERS: dict[str, Callable[[dict], Filter]]  # name -> factory(filter_config)
# built-in: "min_length" — pass iff len(text) >= cfg.get("min", 2)
def render(template: str, message: Message, voices: dict[str, str]) -> tuple[Segment, ...]
class TtsHandlerPlugin:  name = "handler.tts"
```

Config keys: `template` (default `"{user} says: {text}"`; allowed placeholders `{user}`, `{text}`), `filters` (list of names, default `[]`), `voices` (placeholder → voice key, default `{}`), `target` (optional instance name). Behavior: subscribe to `ctx.messages` as `ctx.instance`; skip messages whose `kind != "chat"`; run the filter chain (all must pass); publish `SpeakRequest(segments=render(...), source=m.source, user=m.user, target=self._target)` to `ctx.speak`. Unknown filter name or unknown template placeholder → `ValueError` **at construction** (so it fails at graph build, before any message flows).

`render` rule: split on `{user}`/`{text}`; a placeholder becomes `Segment(value, voice=voices.get(key))`; a literal run becomes `Segment(literal, voice=voices.get(last_key))` — the preceding placeholder's voice key — so `"{user} says: {text}"` with `voices={"user": "samantha", "text": "daniel"}` yields texts `["Alice", " says: ", "nice run"]` with voices `["samantha", "samantha", "daniel"]`.
