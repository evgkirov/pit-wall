# tts.mlx (MLX-Audio TTS) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add `tts.mlx`, a model-agnostic synthesizer plugin using mlx-audio neural TTS, swappable with `tts.say` via config.

**Architecture:** One new plugin module mirrors `tts.say`'s shape — subscribe to `speak`, synthesize each segment to a temp WAV file via two module-level seams (`load_model`, `render_segment`) run in `asyncio.to_thread`, publish `Audio` events, leave playback to `output.local` (afplay plays WAV unchanged). `mlx_audio` is imported lazily inside `load_model` so the module imports and CI runs without the extra.

**Tech Stack:** Python 3.15, asyncio, mlx-audio (optional extra `mlxaudio`), stdlib `wave` + numpy (numpy is a mlx-audio dependency) for WAV writing.

**Spec:** `docs/superpowers/specs/2026-11-22-tts-mlx-design.md`

## Global Constraints

- Plugin name `tts.mlx`; optional extra name `mlxaudio`; default model repo `mlx-community/Kokoro-82M-bf16` (exact strings).
- All tooling via `uv`; single test: `uv run pytest tests/test_tts_mlx.py -q`. Gate order matches CI: `make lint && make typecheck && make test`.
- ruff line-length 100; mypy checks `src/` only; pytest-asyncio is auto mode (async tests need no marker).
- The suite is hermetic: no network, no macOS, no MLX. Tests fake the two seams via `monkeypatch.setattr(tts_mlx, "load_model"/"render_segment", ...)`.
- `src/pitwall/plugins/tts_mlx.py` must import cleanly with mlx-audio NOT installed (no module-level `mlx_audio`/`numpy` imports).
- Plugins are registered in `register_builtins()` in `src/pitwall/plugins/__init__.py`; tests that resolve plugin names call `register_builtins()` first.
- Hot-reload invariant preserved: failures inside `start()` are caught by the runtime supervisor (logged + retried with backoff); no new failure path may abort the process.
- Docs ship with the change on the same branch: README.md and config.toml.example (AGENTS.md). Commit style: conventional (`feat(tts): ...`, `docs: ...`).

## Review Focus

1. **mlx-audio extra not installed** → `load_model` raises `RuntimeError` naming the `mlxaudio` extra, not a bare `ImportError`. → Task 1, `test_missing_extra_raises_helpful_error`.
2. **Bad/missing model repo** → the error propagates out of `start()` (supervisor logs it and retries with backoff; the app stays up). → Task 1, `test_model_load_failure_propagates_from_start`.
3. **Slow synthesis** (neural inference takes seconds per segment) → segments still render and publish strictly in order, none dropped. → Task 1, `test_slow_render_preserves_order`.
4. **Unicode/emoji chat text** → passes through to the renderer unchanged. → Task 1, `test_unicode_survives`.
5. **One segment fails to render** → failure logged, no `Audio` event for it, later segments still synthesized. → Task 1, `test_render_failure_logged_not_fatal`.

```python
import asyncio
import logging
import sys
import time
from pathlib import Path

import pytest

from pitwall.core.channels import Channel
from pitwall.core.events import Segment, SpeakRequest
from pitwall.core.plugin import Context
from pitwall.core.registry import factory_for
from pitwall.plugins import register_builtins, tts_mlx
from pitwall.plugins.tts_mlx import DEFAULT_MODEL, MlxTtsPlugin


class FakeLoader:
    def __init__(self, error: Exception | None = None):
        self.repos: list[str] = []
        self.error = error

    def __call__(self, repo: str):
        self.repos.append(repo)
        if self.error:
            raise self.error
        return object()


class FakeRenderer:
    """Records (text, voice, speed); can fail N times or sleep per call."""

    def __init__(self, failures: int = 0, delay: float = 0.0):
        self.calls: list[tuple[str, str | None, float | None]] = []
        self.failures = failures
        self.delay = delay

    def __call__(self, model, text, voice, speed, path):
        self.calls.append((text, voice, speed))
        if self.failures > 0:
            self.failures -= 1
            raise RuntimeError("synthesis boom")
        if self.delay:
            time.sleep(self.delay)
        Path(path).write_bytes(b"RIFF")


def make_ctx(config: dict) -> Context:
    return Context(
        instance="mix",
        config=config,
        logger=logging.getLogger("pitwall.mix"),
        messages=Channel("messages"),
        speak=Channel("speak"),
        audio=Channel("audio"),
        stopping=asyncio.Event(),
    )


async def run_mlx(
    config: dict,
    requests: list[SpeakRequest],
    loader: FakeLoader,
    renderer: FakeRenderer,
    monkeypatch,
    settle: float = 0.05,
):
    monkeypatch.setattr(tts_mlx, "load_model", loader)
    monkeypatch.setattr(tts_mlx, "render_segment", renderer)
    ctx = make_ctx(config)
    audio_q = ctx.audio.subscribe("speakers")
    plugin = MlxTtsPlugin(config)
    task = asyncio.create_task(plugin.start(ctx))
    await asyncio.sleep(0.01)
    for request in requests:
        await ctx.speak.publish(request)
    await asyncio.sleep(settle)
    ctx.stopping.set()
    await asyncio.wait_for(task, timeout=5)
    await plugin.stop(ctx)
    return audio_q


def request(*segments: Segment, rid="r1") -> SpeakRequest:
    return SpeakRequest(request_id=rid, segments=segments)


def test_registered_in_builtin_registry():
    register_builtins()
    assert factory_for("tts.mlx") is MlxTtsPlugin


def test_missing_extra_raises_helpful_error(monkeypatch):
    monkeypatch.setitem(sys.modules, "mlx_audio", None)
    with pytest.raises(RuntimeError, match="mlxaudio"):
        tts_mlx.load_model("mlx-community/Kokoro-82M-bf16")


async def test_model_defaults_to_kokoro_repo(monkeypatch):
    loader = FakeLoader()
    await run_mlx({}, [request(Segment("hi", index=0))], loader, FakeRenderer(), monkeypatch)
    assert loader.repos == [DEFAULT_MODEL]


async def test_model_config_override(monkeypatch):
    loader = FakeLoader()
    await run_mlx(
        {"model": "mlx-community/Kokoro-82M-8bit"},
        [request(Segment("hi", index=0))],
        loader,
        FakeRenderer(),
        monkeypatch,
    )
    assert loader.repos == ["mlx-community/Kokoro-82M-8bit"]


async def test_renders_segments_with_resolved_voices_and_speed(monkeypatch):
    renderer = FakeRenderer()
    await run_mlx(
        {"voices": {"user": "af_heart", "text": "am_michael"}, "speed": 1.2},
        [request(Segment("alice", voice="user", index=0), Segment("hi", voice="text", index=1))],
        FakeLoader(),
        renderer,
        monkeypatch,
    )
    assert renderer.calls == [("alice", "af_heart", 1.2), ("hi", "am_michael", 1.2)]


async def test_audio_events_carry_request_id_and_index(monkeypatch):
    q = await run_mlx(
        {}, [request(Segment("a", index=0), Segment("b", index=1))], FakeLoader(), FakeRenderer(), monkeypatch
    )
    events = [q.get_nowait(), q.get_nowait()]
    assert [e.index for e in events] == [0, 1]
    assert all(e.request_id == "r1" for e in events)
    assert all(e.path.endswith(".wav") for e in events)
    assert all(Path(e.path).exists() for e in events)
    for e in events:
        Path(e.path).unlink()


async def test_unknown_voice_key_falls_back_with_warning(monkeypatch, caplog):
    caplog.set_level(logging.WARNING, logger="pitwall.mix")
    renderer = FakeRenderer()
    await run_mlx(
        {"voice": "af_heart"},
        [request(Segment("hi", voice="ghost", index=0))],
        FakeLoader(),
        renderer,
        monkeypatch,
    )
    assert renderer.calls == [("hi", "af_heart", None)]
    assert "ghost" in caplog.text


async def test_render_failure_logged_not_fatal(monkeypatch, caplog):
    caplog.set_level(logging.ERROR, logger="pitwall.mix")
    renderer = FakeRenderer(failures=1)
    q = await run_mlx(
        {}, [request(Segment("a", index=0), Segment("b", index=1))], FakeLoader(), renderer, monkeypatch
    )
    assert len(renderer.calls) == 2  # second segment still synthesized
    assert "segment" in caplog.text  # first failure logged
    assert q.qsize() == 1  # no Audio for the failed segment
    event = q.get_nowait()
    assert event.index == 1
    Path(event.path).unlink()


async def test_slow_render_preserves_order(monkeypatch):
    renderer = FakeRenderer(delay=0.03)
    q = await run_mlx(
        {},
        [request(Segment("a", index=0), Segment("b", index=1), Segment("c", index=2))],
        FakeLoader(),
        renderer,
        monkeypatch,
        settle=0.25,
    )
    events = []
    while not q.empty():
        events.append(q.get_nowait())
    assert [e.index for e in events] == [0, 1, 2]
    assert [c[0] for c in renderer.calls] == ["a", "b", "c"]
    for e in events:
        Path(e.path).unlink()


async def test_unicode_survives(monkeypatch):
    renderer = FakeRenderer()
    await run_mlx({}, [request(Segment("😀 hi", index=0))], FakeLoader(), renderer, monkeypatch)
    assert renderer.calls[0][0] == "😀 hi"


async def test_model_load_failure_propagates_from_start(monkeypatch):
    loader = FakeLoader(error=RuntimeError("no such repo"))
    monkeypatch.setattr(tts_mlx, "load_model", loader)
    ctx = make_ctx({})
    plugin = MlxTtsPlugin({})
    with pytest.raises(RuntimeError, match="no such repo"):
        await asyncio.wait_for(plugin.start(ctx), timeout=5)
    await plugin.stop(ctx)
```

Module docstring in the style of `tts_say.py` ("tts.mlx: synthesize segments to WAV files with local MLX-Audio models. A synthesizer only..."). Definitions:

- `def render_segment(model: Any, text: str, voice: str | None, speed: float | None, path: str) -> None:` — sync. Body (the one algorithm the tests can't determine; `numpy` is imported inside the function with a `# type: ignore` comment since it is absent from the dev venv):

```python
kwargs: dict[str, Any] = {}
if voice is not None:
    kwargs["voice"] = voice
if speed is not None:
    kwargs["speed"] = speed
chunks: list[Any] = []
sample_rate = 0
for result in model.generate(text, **kwargs):
    if not chunks:
        sample_rate = result.sample_rate
    chunks.append(result.audio)
import numpy as np  # type: ignore

audio = np.concatenate([np.asarray(c) for c in chunks])
pcm = (np.clip(audio, -1.0, 1.0) * 32767.0).astype("<i2")
with wave.open(path, "wb") as w:
    w.setnchannels(1)
    w.setsampwidth(2)
    w.setframerate(sample_rate)
    w.writeframes(pcm.tobytes())
```

- `class MlxTtsPlugin:` with `name = "tts.mlx"` and `__init__(self, config: dict | None = None)` storing `dict(config or {})`. Methods:
  - `async def start(self, ctx: Context) -> None:` — `repo = self._config.get("model", DEFAULT_MODEL)`; `model = await asyncio.to_thread(load_model, repo)` (errors propagate — see Review Focus 2); then copy the subscribe/wait/unsubscribe pattern exactly from `SayTtsPlugin.start` (`src/pitwall/plugins/tts_say.py:51-63`), calling `await self._synthesize(ctx, model, request)` per request. Call the seams as bare module-level names (`load_model`, `render_segment`) so monkeypatching works.
  - `async def stop(self, ctx: Context) -> None:` — `ctx.speak.unsubscribe(ctx.instance)` (safe even if `start` failed before subscribing; `Channel.unsubscribe` pops with a default).
  - `async def _synthesize(self, ctx: Context, model: Any, request: SpeakRequest) -> None:` — mirror `SayTtsPlugin._synthesize` (`tts_say.py:68-95`) with: `voices`/`speed` read from `self._config`; the same unknown-voice-key warning text; `resolve_voice` imported from `pitwall.plugins.tts_say`; `tempfile.mkstemp(suffix=".wav", prefix=f"pitwall-{request.request_id[:8]}-")`; `await asyncio.to_thread(render_segment, model, segment.text, voice, speed, path)` in place of the subprocess call; same exception handling (log via `ctx.logger.exception`, `Path(path).unlink(missing_ok=True)`, `continue`); then `await ctx.audio.publish(Audio(path=path, request_id=request.request_id, index=segment.index, source=request.source, user=request.user))`.

In `src/pitwall/plugins/__init__.py`: add `from pitwall.plugins.tts_mlx import MlxTtsPlugin` (alphabetical: before the `tts_say` import) and `register("tts.mlx", MlxTtsPlugin)` inside `register_builtins()`.
